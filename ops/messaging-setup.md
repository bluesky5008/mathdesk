# 문자·카카오 알림톡 발송 준비

mathdesk에서 학부모에게 실제로 문자나 카카오 알림톡을 보내기 위해 준비할 서류와 절차를 정리한다. 지금 테스트 운영은 **테스트 모드**라 아무것도 밖으로 나가지 않고 발송 내역에만 남는다.

- 조사일: 2026-09-24. 요금·심사 기간은 바뀔 수 있으니 신청 직전에 [출처](#출처)의 원문을 다시 확인한다.
- 전제: 클라이언트는 원장이 아니고 **사업자등록증이 없다.**

## 한눈에 보기

| | 문자(SMS·LMS) | 카카오 알림톡 |
|---|---|---|
| 사업자등록증 없이 가능한가 | **가능.** 본인 명의 휴대폰 번호로 보낸다 | **불가.** 사업자등록번호(또는 고유번호)가 있는 비즈니스 채널만 보낼 수 있다 |
| 준비 기간 | 하루 안(번호 등록 1~3시간) | 1~2주(채널 인증 1~5영업일 + 템플릿 심사 2~5영업일) |
| 건당 요금(알리고, VAT 별도) | SMS 8.4원 · LMS 25.9원 | 6.5원(실패분 환불, 대체 문자 요금만 부과) |
| 보낼 수 있는 내용 | 제한 없음(광고성은 법적 표기·야간 제한 적용) | **정보성만**(수업·출결·성적 안내). 광고 문구가 섞이면 반려 |
| mathdesk 쪽 준비 | 서버 설정 4개 | 서버 설정 1개 추가 + 템플릿 등록 |

**권장:** 문자로 시작한다. mathdesk의 일일 피드백은 대부분 90바이트를 넘어 LMS(25.9원)로 나간다. 알림톡은 소속 학원 명의를 쓸 수 있게 되면 그때 더한다. 코드는 두 경우를 모두 이미 지원한다.

## 1. 문자 발송 준비 (사업자등록 불필요)

### 준비물

| 준비물 | 비고 |
|---|---|
| 클라이언트 **본인 명의 휴대폰** | 이 번호가 학부모에게 보이는 발신번호가 된다. 다른 사람·학원 명의 번호는 사업자 인증이 필요하다 |
| 본인인증 수단 | 휴대폰 본인인증. 본인 명의 휴대폰을 발신번호로 쓰면 **제출 서류가 없다** |
| 충전금 | 가입 시 최소 5만원(VAT 포함 5.5만원) 선충전, 5년간 사용 |
| (선택) 본인 명의 유선전화 | 쓰려면 통신서비스 이용증명원(발급 1개월 이내, 주민번호 뒷자리 가림) |

### 절차

| 순서 | 담당 | 할 일 |
|---|---|---|
| 1 | 클라이언트 | [알리고](https://smartsms.aligo.in/)에 **개인 회원**으로 가입하고 충전한다 |
| 2 | 클라이언트 | [발신번호] → [발신번호 관리] → [발신번호 추가하기]에서 본인 휴대폰을 등록한다. 명의는 "개인 회원 · 본인"으로 고른다. 승인까지 평일 기준 평균 1~3시간 |
| 3 | 클라이언트 | 번호가 통신사 **번호도용 문자차단 서비스**에 가입되어 있으면 해지한다(해지 후 2~3일 뒤부터 발송 가능) |
| 4 | 클라이언트 | 알리고에서 **API 키**를 발급받고 **발송 서버 IP**를 등록한다. 서버는 맥미니이므로 그 인터넷의 공인 IP를 등록한다(개발 담당이 IP를 알려 준다) |
| 5 | 개발 | 아래 [서버 설정](#3-서버-설정-개발)을 넣고 재배포한 뒤, 본인 번호로 시험 발송한다 |

클라이언트가 개발 담당에게 넘길 값: **알리고 아이디, API 키, 등록한 발신번호.**

## 2. 카카오 알림톡 준비 (사업자등록 필요)

### 조건

카카오는 알림톡을 **비즈니스 채널**에서만 보내게 한다. 비즈니스 채널 인증은 사업자등록증(또는 비영리단체의 고유번호증)으로만 신청할 수 있고, 신청 경로는 개인사업자 대표·법인 대표·그 사업자의 **직원**·대행사 네 가지뿐이다. 사업자등록번호가 없는 개인은 알림톡을 보낼 수 없다.

클라이언트가 쓸 수 있는 길은 둘이다.

| 길 | 채널 명의 | 필요한 것 | 비고 |
|---|---|---|---|
| **A. 소속 학원의 직원으로 신청** | 학원 | 학원 사업자등록증(원장 협조), 클라이언트 본인 카카오톡 전자증명서 | 학부모에게 학원 이름으로 보인다. 원장 동의가 필요하다 |
| B. 클라이언트 본인이 사업자등록 | 클라이언트 | 본인 사업자등록증 | 홈택스에서 무료 등록. 세금 신고 의무가 생기므로 본인이 판단한다 |

### 준비물 (A. 학원 직원 기준)

| 준비물 | 어디에 |
|---|---|
| 학원 **사업자등록증** 사본(jpg·png·pdf, 10MB 이하) | 카카오 비즈니스 인증, 알리고 사업자 인증 |
| 클라이언트 본인 명의 **카카오톡 전자증명서** | 카카오 비즈니스 인증(직원 신청) |
| (알리고가 요구하면) **재직증명서** | 알리고 사업자 인증·학원 명의 발신번호 등록 |
| 채널 **검색용 아이디**(예: `@학원이름`) | 발신프로필 등록 |
| 채널 관리자 휴대폰 | 발신프로필 등록 시 인증번호 수신 |
| 승인받을 **템플릿 문구** | 알림톡 템플릿 심사 |

서류는 개인정보를 가리지 않은 원본 그대로 식별되어야 한다(가리면 반려되는 사례가 많다).

### 절차

| 순서 | 담당 | 할 일 | 소요 |
|---|---|---|---|
| 1 | 클라이언트 | [카카오비즈니스 파트너센터](https://business.kakao.com/)에서 카카오톡 채널을 만든다. 채널 이름·검색용 아이디를 학원명으로 정한다 | 즉시 |
| 2 | 클라이언트 | 채널에서 **비즈니스 인증**을 신청한다(직원 신청: 학원 사업자등록증 + 본인 전자증명서) | 1~5영업일 |
| 3 | 클라이언트 | 채널 설정에서 **홈 공개 ON**, **고객센터 정보**(연락처)를 입력한다 | 즉시 |
| 4 | 클라이언트 | 알리고에서 **사업자 인증**을 신청한다(학원 사업자등록증) | 알리고 심사 |
| 5 | 클라이언트 | 알리고 [카카오톡] 메뉴에서 **발신프로필**을 등록한다: 검색용 아이디 입력 → 관리자 휴대폰 인증번호 → 카테고리 선택 → **발신프로필 키** 발급 | 즉시 |
| 6 | 클라이언트·개발 | 보낼 문구로 **템플릿**을 만들어 알리고에 등록하고 **검수 요청**까지 한다(등록만 하면 심사가 시작되지 않는다) | 2~5영업일 |
| 7 | 개발 | 발신프로필 키를 [서버 설정](#3-서버-설정-개발)에 넣고, 승인된 템플릿을 mathdesk [알림문자 → 알림톡 템플릿]에 **글자 하나 다르지 않게** 붙여 넣고 변수를 연결한다 | 즉시 |
| 8 | 개발 | 본인 번호로 시험 발송하고, 카카오톡이 없는 번호로 문자 대체가 오는지 확인한다 | 즉시 |

클라이언트가 개발 담당에게 넘길 값: 1번의 알리고 값 + **발신프로필 키** + **승인된 템플릿 코드와 본문.**

### 템플릿 작성 요령

- **정보성만** 쓴다: 수업 내용, 출결, 과제, 테스트 점수. 원생 모집·이벤트·할인·"친구 추천" 같은 문구가 한 줄이라도 있으면 반려된다.
- 학생마다 바뀌는 부분은 `#{변수}`로 둔다. 본문 전체를 변수 하나로 만들면 반려된다(변수 40개 초과도 반려).
- 발송 주체와 목적이 드러나야 한다(학원명·"수업 안내" 등).
- mathdesk에서 변수에 넣을 수 있는 값: 학생 이름, 학원명, 담당 강사, 수업일, 출결, 수업 진도, 과제 등급, 등급 문구, 테스트명, 학생 점수, 반 평균, 오늘의 과제, 수업 영상 링크, 일일 피드백 전체.

예시 초안(심사 통과를 보장하지 않는다):

```text
[#{학원명}] #{학생명} 학생 수업 안내

수업일: #{수업일}
출결: #{출결}
과제 등급: #{과제등급}
오늘의 과제: #{과제}

문의는 학원으로 연락 주세요.
```

### 알림톡이 실패하면

mathdesk [알림톡 템플릿]의 "알림톡이 실패하면 문자로 대체 발송"이 켜져 있으면(기본값):

- 알리고가 알림톡 요청을 **거절**하면 mathdesk가 같은 문구를 문자로 다시 보낸다. 두 시도가 모두 [발송 내역]에 남는다.
- 요청은 접수됐지만 **전달 단계에서 실패**하면(학부모가 카카오톡을 쓰지 않는 등) 알리고가 문자로 대체한다. 이 대체는 **알리고 사이트의 발송 내역에만** 남는다.

## 3. 서버 설정 (개발)

저장소 루트 `.env`에 넣고 테스트 운영을 다시 올린다. 값은 git에 올리지 않는다.

```bash
MATHDESK_MESSAGING_MODE=live
ALIGO_API_KEY=발급받은_API_키
ALIGO_USER_ID=알리고_아이디
ALIGO_SENDER=01012345678        # 알리고에 등록한 발신번호
ALIGO_SENDER_KEY=발신프로필_키   # 알림톡을 쓸 때만. 없으면 알림톡만 실패하고 문자는 나간다
```

```bash
docker compose -f compose.testops.yaml up -d            # .env 변경 반영
curl -s https://mathdesk.yongs-wiki.com/api/health
```

- 확인: [알림문자] 화면 잔액 조회가 `live`로 바뀌고 SMS·LMS 잔여 건수가 보여야 한다.
- 발송 서버 공인 IP 확인: `curl -s https://api.ipify.org` (맥미니에서). 알리고에 등록한 IP와 같아야 한다. 인터넷 공유기를 바꾸거나 통신사가 IP를 바꾸면 다시 등록한다.
- 되돌리기: `MATHDESK_MESSAGING_MODE`를 지우거나 `test`로 바꾸고 다시 올린다.
- **주의:** 실발송을 켜기 전에 테스트 운영의 합성 데이터(가짜 학부모 번호)를 실제 번호로 바꾸지 않았는지, 반대로 실제 학생 정보를 넣었다면 `director`/`director` 자격 증명을 먼저 교체했는지 확인한다([README 알려진 제약](README.md#알려진-제약)).
