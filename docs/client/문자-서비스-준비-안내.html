학부모 문자 발송 서비스 가입 순서

작성일 2026-10-11 받는 분 핑수 보내는 사람 용스

핑수님, mathdesk가 학부모님께 수업 피드백 문자를 실제로 보내려면 문자 발송 서비스에 가입해 두어야 합니다. 지금 테스트 서버는 "보내기"를 눌러도 밖으로 나가지 않고 발송 내역에만 남는 상태입니다. 지난번 "정식 운영 준비 안내"의 "③ 문자 서비스 가입"을 어떤 서비스를 왜 고르는지부터 순서대로 풀어 쓴 안내입니다.

가입과 충전은 모두 핑수님 명의로 합니다. 학부모님 휴대폰에는 핑수님 본인 번호가 보내는 사람으로 뜹니다. 저는 가입이 끝난 뒤 받은 값 세 가지를 서버에 넣고 시험 문자를 보내는 일만 합니다. 서버(AWS)·주소 준비와는 따로 진행해도 되고, 전체 소요는 약 1시간에 번호 승인 대기 1~3시간입니다.

핑수님 혼자 하시는 단계 함께 같이 보는 단계 용스 제가 하는 단계

1한눈에 보기

  1. 준비물 확인 핑수님 5분

    본인 명의 휴대폰, 결제 수단, 통신사 부가서비스 하나만 확인하면 됩니다.

  2. 알리고 개인 회원 가입 핑수님 10분

    휴대폰 본인인증으로 가입합니다. 사업자등록증은 필요 없습니다.

  3. 첫 충전 핑수님 5분

    5만 원(부가세 포함 5.5만 원)부터 충전할 수 있고 5년 동안 쓸 수 있습니다.

  4. 발신번호 등록 핑수님 5분, 승인 1~3시간

    핑수님 휴대폰 번호를 본인인증으로 등록합니다. 서류는 없습니다.

  5. API 키 발급과 서버 주소 등록 함께 10분

    mathdesk 서버가 알리고에 문자를 맡길 수 있게 열쇠를 만들고 서버 주소를 적어 둡니다.

  6. 시험 발송 용스 10분

    핑수님 번호로 시험 문자를 보내 확인하면 끝입니다.

2어느 서비스를 쓸까요

조건은 두 가지였습니다. 사업자등록증 없이 개인이 가입해 본인 번호로 보낼 수 있을 것, 그리고 mathdesk 서버가 자동으로 보낼 수 있는 연결 창구(API)를 열어 줄 것. 국내에서 많이 쓰는 서비스 다섯 곳을 이 기준으로 확인했습니다.

5제가 하는 일 용스

핑수님은 이 장을 읽지 않으셔도 됩니다. 현재 mathdesk의 문자 기능 상태와 실발송을 켜기 전에 제가 손볼 부분입니다.

서버 설정과 실발송 전 보완 펼치기

현재 상태(2026-10-11 검토). 발송 어댑터(알리고 문자·알림톡·테스트 모드), 본문 길이에 따른 단문/장문 자동 선택, 수신자별 발송 로그(본문 스냅샷·비용), 알림톡 실패 시 문자 대체, 잔액 조회 API까지 구현되어 있고 테스트 모드가 기본값이다. 실발송은 환경변수 4개로 켠다. 실제 알리고 호출은 아직 한 번도 해 보지 않았다(Q-02).

A. 서버 설정

# 서버의 mathdesk/.env (chmod 600). 저장소·메신저로 옮기지 않는다
MATHDESK_MESSAGING_MODE=live
ALIGO_API_KEY=<핑수님이 발급한 API 키>
ALIGO_USER_ID=<알리고 아이디>
ALIGO_SENDER=010xxxxxxxx        # 승인된 발신번호, 숫자만
# ALIGO_SENDER_KEY=              # 알림톡을 쓸 때만

docker compose -f compose.testops.yaml up -d   # 정식 서버는 compose.prod.yaml
curl -s https://<주소>/api/health

B. 실발송 전에 보완할 것 (검토에서 찾은 빈틈)

  • 잔액 표시 화면이 없다. API(/messages/balance)만 있고 알림문자 화면에 잔액·모드가 보이지 않는다(FR-23 상세). 충전 시점을 놓치면 발송이 조용히 실패하므로 먼저 넣는다.
  • 전화번호를 정리하지 않고 보낸다. 학생·학부모 번호는 자유 입력(20자)이라 하이픈·공백이 섞일 수 있다. 발송 직전에 숫자만 남기도록 정규화한다.
  • 발송 상태는 "접수"까지다. 알리고가 돌려주는 msg_id를 저장하지 않아 통신사 전달 실패를 나중에 알 수 없다. msg_id 저장과 전송 결과 조회를 더한다.
  • 실패 건 재시도 버튼이 없다(설계 흐름 5번). 로그에만 남는다.
  • 이미지 첨부(MMS)는 미구현. 리포트 카드는 복사·저장만 되고 문자에 붙여 보내지는 않는다. 당장은 장문 문자로 충분하면 보류.
  • 학생 한 명씩만 보낸다. 반 전체 일괄 발송이 없어 160명이면 160번 보내야 한다. 운영 전에 반 단위 일괄 발송이 필요한지 핑수님과 정한다.
  • 설정이 환경변수뿐이다. 발신번호·키를 바꾸려면 재배포가 필요하다. 설계(DES-20)의 설정 화면은 미구현이지만 바꿀 일이 드물어 후순위.
  • 실발송 문자 경로의 자동 테스트가 없다. 알림톡 요청 테스트만 있다. 알리고 문자 요청 형식(필수 5개 필드·msg_type)을 고정하는 테스트를 더한다.
  • 하루 한도. 알리고 약관상 개인 회원은 하루 500통까지 제한될 수 있다. 160명 전원에게 같은 날 보내도 160건이라 괜찮지만, 학생이 늘면 사전 승인을 받는다.

상세 절차와 출처는 저장소의 ops/messaging-setup.md에 있다. 보완 항목은 사용자 결정 뒤 TASK로 등록한다.

6알아 두실 점

  • 보내는 내용은 "정보성" 문자입니다. 수업 내용·출결·과제·점수 안내는 광고가 아니라서 "(광고)" 표기나 080 수신거부 번호가 필요 없고 밤에도 보낼 수 있습니다. 다만 원생 모집·이벤트 같은 문구를 섞으면 광고 문자 규정(표기·야간 금지)이 적용되니 섞지 마세요.
  • 문자를 원치 않는 학부모님이 있으면 mathdesk 학생 정보에서 학부모 연락처를 비우거나 알림 대상에서 빼면 그분께는 나가지 않습니다.
  • 답장은 핑수님 휴대폰으로 옵니다. 발신번호가 핑수님 번호라서 학부모님이 답장하면 핑수님 폰 문자함에 도착합니다.
  • 충전금 관리: 알리고 사이트 첫 화면에 잔액이 보입니다. 자동 충전은 없으니 한 달에 한 번 확인해 주세요. 정식 서버에서는 mathdesk 화면에도 보이게 할 예정입니다.
  • 나중에 알림톡으로 바꾸면 건당 요금이 1/4로 줄고 카카오톡으로 받습니다. 학원 사업자등록증(원장님 협조)이 있으면 1~2주 심사로 가능하고, mathdesk는 추가 개발 없이 전환됩니다. 조건이 되면 말씀해 주세요.
  • 제 접근을 끊고 싶으실 때: 알리고 API 인증 화면에서 키를 재발급하면 제가 가진 키는 바로 무효가 됩니다. 서버의 문자 발송도 그 순간 멈춥니다.

7막힐 때

증상해결
API 키 메뉴가 안 보여요휴대폰 화면(홈·내정보·결제정보만 있는 화면)에는 없습니다. 로그인한 채로 smartsms.aligo.in/admin/api/auth.html을 직접 열거나, PC에서 왼쪽 메뉴 문자API → 신청/인증으로 가세요. 사업자 인증은 필요 없습니다.
발신번호 등록에서 서류를 내라고 해요명의를 "본인"으로 골랐는지, ②에서 본인인증한 번호와 같은 번호인지 확인하세요. 다른 사람 명의 번호는 개인 회원으로 등록할 수 없습니다.
반나절이 지나도 발신번호가 "대기"예요알리고 심사는 평일 10~17시에만 진행됩니다. 다음 영업일까지 기다리시고, 그래도 그대로면 알리고 고객센터(02-511-4560)에 문의하세요.
시험 문자가 안 와요①의 번호도용 문자차단이 켜져 있거나 해지한 지 2~3일이 안 됐을 수 있습니다. 그다음은 제가 서버 주소 등록과 설정을 다시 봅니다.
"잔액 부족"으로 실패해요알리고에서 충전하면 바로 다시 보낼 수 있습니다. 실패한 문자는 자동으로 다시 나가지 않으니 mathdesk에서 다시 보내 주세요.
API 키를 메신저로 보내 버렸어요알리고 API 인증 화면에서 재발급하시고 새 키를 통화로 알려 주세요. 이전 키는 즉시 못 쓰게 됩니다.
