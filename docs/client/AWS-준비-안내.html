AWS 계정 준비와 서버 이전 순서

작성일 2026-10-11 받는 분 핑수 보내는 사람 용스

핑수님, 지난번 보내 드린 "정식 운영 준비 안내"의 "④ 서버(AWS) 계정 만들기"를 따라 하실 수 있게 순서대로 풀어 쓴 안내입니다.

AWS 계정은 핑수님 명의로 만들고 결제도 핑수님 카드로 됩니다. 저는 핑수님 계정 안에 서버만 다룰 수 있는 제 전용 사용자를 하나 받아서 그걸로 서버를 설치합니다. 나중에 제 접근을 끊고 싶으시면 그 사용자 하나만 지우시면 됩니다.

각 단계 옆의 표시로 누가 하는지 구분했습니다.

핑수님 혼자 하시는 단계 같이 전화나 화면 공유로 함께 용스 제가 하는 단계

1한눈에 보기

  1. 가입 전 준비물 챙기기 핑수님 5분

    이메일, 휴대폰, 카드, 인증 앱.

  2. AWS 가입 핑수님 20~30분, 승인까지 최대 하루

    반드시 아래에 드리는 링크로 가입해 주세요. 다른 경로로 가입하면 서버를 한국(서울)에 둘 수 없습니다.

  3. 계정 잠금 장치(2단계 인증) 켜기 핑수님 10분

    휴대폰 인증 앱으로 로그인할 때마다 6자리 숫자를 한 번 더 넣게 합니다.

  4. 요금 알림 설정 핑수님 5분

    한 달 요금이 정한 금액을 넘으려 하면 이메일이 옵니다.

  5. 용스 전용 사용자 만들기 같이 20분

    화면을 같이 보면서 만듭니다. 서버(Lightsail)만 다룰 수 있고 결제·계정 정보는 볼 수 없는 사용자입니다.

  6. 서버 설치와 이전 용스 기능 승인 후 하루

    서울에 서버를 만들고 mathdesk를 설치합니다. 문자 발송까지 확인한 뒤 원장 계정을 드립니다.

2서버 비용

항목요금설명
서버 (Lightsail 2GB)월 12달러메모리 2GB, 저장 공간 60GB, 데이터 전송 월 3TB 포함. 고정 금액입니다
매일 자동 백업 (스냅샷)월 1~3달러최근 7일치를 보관합니다. 1GB당 월 0.05달러
부가세10%개인 가입자도 붙습니다
합계월 약 2만 원1달러 = 1,400원 기준. 지난 안내문의 "서버 약 2.1만 원"과 같습니다
  • 가입하면 100달러 크레딧을 줍니다. 크레딧이 남아 있는 동안은 서버 요금이 크레딧에서 빠집니다. 위 금액이면 대략 첫 6~7개월 서버 요금이 크레딧으로 충당됩니다. 크레딧은 가입 후 12개월 안에 써야 합니다.
  • 원화로 결제됩니다. 계약 상대는 AWS 한국 법인(Amazon Web Services Korea)이고, 카드 결제는 원화로만 됩니다. 영수증에 달러 금액, 원화 금액, 적용 환율이 함께 나옵니다.
  • 쓰다 보니 느리면 화면에서 몇 번 눌러 한 단계 큰 서버(4GB, 월 24달러)로 옮길 수 있습니다. 그때는 미리 말씀드리겠습니다.

3핑수님께서 하실 일

비밀번호, 인증번호, 6자리 코드, 카드 정보는 메신저나 이메일로 보내지 말아 주세요. 제가 그런 값을 따로 여쭤보는 일도 없습니다. 5단계에서 제 사용자의 첫 비밀번호만 화면 공유로 받아 적고, 저는 받자마자 바꿉니다.

핑수님은 이 장을 읽지 않으셔도 됩니다. 제가 따라 할 작업 순서이고, 무엇을 하는지 궁금하실 때 참고하시면 됩니다.

C. 서버 기본 설정

# 시간대·업데이트 (Ubuntu는 보안 업데이트 자동 설치가 기본으로 켜져 있다)
sudo timedatectl set-timezone Asia/Seoul
sudo apt update && sudo apt -y upgrade

# 메모리 2GB라 이미지 빌드 때 모자랄 수 있어 스왑 2GB
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile
sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# Docker Engine + compose 플러그인 (공식 설치 스크립트)
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker ubuntu   # 다시 로그인하면 sudo 없이 docker

D. mathdesk 설치

git clone https://github.com/bluesky5008/mathdesk.git && cd mathdesk
cp .env.example .env && chmod 600 .env
# .env는 서버에서 직접 채운다(저장소·메신저로 옮기지 않는다)
#   POSTGRES_PASSWORD           openssl rand -base64 24 로 새로 만든다
#   MATHDESK_INITIAL_ADMIN_*    초기 원장 계정. 이전 날 핑수님이 비밀번호를 바로 바꾼다
#   ALIGO_* / MATHDESK_MESSAGING_MODE=live, LLM 키   이전 날 같이 발급해 넣는다

# Cloudflare 터널: 핑수님 Cloudflare에 관리자로 초대받은 계정으로 승인
cloudflared tunnel login
cloudflared tunnel create mathdesk-prod
cloudflared tunnel route dns mathdesk-prod <정식 도메인>

# 운영 구성 파일(TASK-57에서 준비)로 기동. 마이그레이션은 기동 시 자동 적용
docker compose -f compose.prod.yaml up -d --build

E. 확인과 인계

5이전한 뒤에

  • 요금 확인: 매달 초 AWS에서 청구 이메일이 옵니다. 첫 몇 달은 크레딧에서 빠져 0원으로 보일 수 있습니다.
  • 제 접근을 끊고 싶으실 때: 루트로 로그인 → IAM → 사용자 → yongs 체크 → 삭제 Delete. 서버와 자료는 그대로 남고 제 로그인만 막힙니다.
  • 루트 계정은 핑수님만: 루트 비밀번호와 인증 앱은 누구와도 나누지 마세요. 제가 루트로 로그인해야 하는 일은 없습니다.

6막힐 때

증상해결
인증 문자가 안 와요국가가 대한민국 (+82)인지, 번호가 맞는지 확인하고 다시 보내 보세요. 통신사에서 해외 발신 문자를 막는 경우가 있습니다. 같은 번호로 다른 AWS 계정을 만든 적이 있어도 실패할 수 있습니다. 계속 안 되면 화면의 고객 지원 문의(Account activation → Phone verification)로 요청하시거나 저에게 연락 주세요.
가입 화면에 플랜 선택이나 리전 이야기가 없고, AWS Builder ID로 로그인하라고 나와요"새 가입 화면"으로 들어가신 겁니다. 창을 닫고 위의 가입 주소로 다시 시작해 주세요. 이미 그 화면으로 가입을 마치셨다면 저에게 말씀해 주세요. 고급 기능을 켜는 절차가 따로 있습니다.
카드에서 1달러가 결제됐어요카드 확인용 승인입니다. 3~5일 안에 취소됩니다.
가입했는데 서비스를 쓸 수 없다고 나와요계정 활성화가 끝나지 않은 상태입니다. 활성화 이메일이 올 때까지(최대 하루) 기다려 주세요.
휴대폰을 바꾸거나 잃어버렸어요③에서 적어 두신 비밀 키로 새 휴대폰 인증 앱에 다시 등록하시면 됩니다. 비밀 키가 없으면 AWS 본인 확인 절차를 거쳐야 하니, 미리 적어 두시는 게 중요합니다.
