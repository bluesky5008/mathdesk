# mathdesk 정식 운영 준비 안내

> 작성일: 2026-09-24 · 받는 분: mathdesk 사용 선생님 · 보내는 사람: 개발 담당

안녕하세요. 지금 확인하고 계신 mathdesk는 **테스트용 서버**(`mathdesk.yongs-wiki.com`)에서 돌아가고 있고, 안에 들어 있는 학생·반은 모두 **가짜 데이터**입니다. 선생님께서 기능을 확인하고 "이대로 쓰겠다"고 승인해 주시면, 실제 학생 정보를 넣어 쓸 **정식 서버**로 옮깁니다.

이 안내문은 그 과정에서 **선생님께서 준비해 주셔야 할 것**과 **매달 드는 비용**을 정리한 것입니다.

---

## 1. 전체 흐름

| 단계 | 기간 | 내용 |
|---|---|---|
| ① 기능 확인 | 지금 ~ 승인 전 | 테스트 서버에서 써 보시고 고칠 점을 알려 주세요. 요청하신 내용은 반영해서 바로 테스트 서버에 올립니다 |
| ② 계정 준비 | ①과 **동시에** (1~2주) | 아래 3장의 준비물을 미리 만들어 두시면 승인 뒤 바로 옮길 수 있습니다. 심사 기간이 있는 항목이 있어 미리 시작하시는 게 좋습니다 |
| ③ 승인 | — | 실제 쓰시는 순서대로 한 번 따라 해 보신 뒤 승인해 주세요 |
| ④ 정식 서버 이전 | 승인 후 하루 | 새 주소로 정식 서버를 열고, 문자 발송까지 확인한 뒤 계정을 드립니다 |
| ⑤ 안정화 | 이전 후 1~2주 | 백업·비용·오류를 지켜보며 문제가 없는지 확인합니다 |

정식 서버는 **빈 상태로 시작**합니다. 테스트 서버의 가짜 데이터는 옮기지 않고, 학생·반·학부모 연락처는 정식 서버에서 새로 입력하시게 됩니다.

---

## 2. 매달 드는 비용 (예상)

아래 조건을 가정한 금액입니다. **모든 금액은 부가세(10%) 포함**입니다.

- 반 **8개**, 반마다 학생 **20명**(총 160명)
- 학생 1명당 학부모 1명에게 **주 8회** 문자 발송 → 한 달 약 **5,500건**
- 시험지 분석 **하루 1회**(한 달 30건)

### 항목별

| 항목 | 한 달 비용 | 설명 |
|---|---|---|
| 문자 발송 (장문 LMS) | **약 15.8만 원** | 수업 피드백 문자는 길어서 대부분 장문으로 나갑니다(건당 25.9원+부가세) |
| 시험지 분석 (AI) | **약 2.4만 ~ 8.5만 원** | 시험지 1건에 약 800 ~ 2,800원. 정확한 금액은 첫 달에 실제로 재서 알려 드립니다 |
| 서버 (AWS) | 약 2.1만 원 | 반 수와 관계없이 고정 |
| 인터넷 주소 (도메인) | 약 0.1만 원 | 1년에 약 1.5만 원 |
| **합계** | **약 20만 ~ 27만 원** | |

### 줄일 수 있는 방법

| 방법 | 한 달 합계 | 조건 |
|---|---|---|
| 지금 방식 (장문 문자) | 약 20만 ~ 27만 원 | 바로 가능 |
| 짧은 문자 위주로 보내기 | 약 10만 ~ 16만 원 | 문자 내용을 90바이트(한글 약 45자) 이하로 줄여야 합니다 |
| **카카오 알림톡**으로 보내기 | 약 10만 ~ 16만 원 | **사업자등록증이 필요합니다.** 아래 3-⑤를 봐 주세요 |

### 처음에 한 번 드는 비용

- 문자 서비스(알리고) 첫 충전: 최소 5.5만 원. 5년 동안 쓸 수 있는 선불금입니다. 다만 위 발송량이면 **열흘이면 다 쓰게 되니**, 한 달에 20만 원 정도씩 충전하시는 걸 권합니다.
- 인터넷 주소 1년치: 약 1.5만 원

> 참고: 서버(AWS)와 AI는 달러로 청구되어 환율에 따라 조금씩 달라집니다. 위 금액은 1달러 = 1,400원으로 계산했습니다.

## 3. 선생님께서 준비해 주실 것

체크하시면서 진행해 주세요. 막히는 부분은 언제든 말씀해 주시면 같이 하겠습니다.

**중요:** 비밀번호·인증번호·API 키 같은 값은 **메신저나 이메일로 보내지 말아 주세요.** 이전 날 제가 직접 입력하거나, 화면을 같이 보면서 입력하는 방식으로 하겠습니다.

### ① 인터넷 주소(도메인) 사기 — 소요 10분

- [ ] 정식 서버 주소로 쓸 이름을 정합니다. 예: `○○math.com`, `○○수학.kr`
- [ ] 가비아(gabia.com) 같은 도메인 판매 사이트나 Cloudflare에서 구입합니다(1년 약 1.5만 원).
- [ ] **선생님 명의**로 사 주세요. 주소는 선생님의 자산입니다.

### ② Cloudflare 가입 — 소요 20분

- [ ] Cloudflare(cloudflare.com)에 **무료 플랜**으로 가입합니다.
- [ ] 산 도메인을 Cloudflare에 추가합니다. 도메인 판매 사이트에서 "네임서버"를 Cloudflare가 알려 주는 값으로 바꾸는 단계가 있습니다. 이 부분은 같이 하시면 쉽습니다.
- [ ] 개발 담당을 관리자로 초대해 주세요.

이 서비스가 정식 서버 주소에 보안 연결(https)을 자동으로 붙여 줍니다.

### ③ 문자 서비스(알리고) 가입 — 소요 30분, 번호 승인 1~3시간

- [ ] 알리고(smartsms.aligo.in)에 **개인 회원**으로 가입하고 충전합니다(최소 5.5만 원).
- [ ] **선생님 본인 휴대폰 번호**를 발신번호로 등록합니다. 본인인증만 하면 되고 서류는 필요 없습니다. 학부모님께는 이 번호로 문자가 갑니다.
- [ ] 쓰시는 통신사의 **"번호도용 문자차단" 서비스**가 켜져 있으면 해지해 주세요. 켜져 있으면 문자가 나가지 않습니다(해지 후 2~3일 뒤부터 가능).
- [ ] 이전 날, 알리고의 "API 키 발급"과 "발송 서버 IP 등록"을 같이 하겠습니다.

> 학원 전화번호나 다른 사람 명의 번호로 보내려면 사업자 인증이 필요해서, 지금은 선생님 본인 번호만 가능합니다.

### ④ 서버(AWS) 계정 만들기 — 소요 30분

- [ ] AWS(aws.amazon.com)에 가입합니다. **국내 카드사에서 발급한 카드**가 필요하고, 요금은 원화로 결제되며 부가세 10%가 붙습니다.
- [ ] 가입 직후 계정 보안(2단계 인증, MFA)을 켭니다.
- [ ] 개발 담당이 서버를 설정할 수 있게 관리자 사용자를 하나 만들어 주세요. 이 부분도 화면을 같이 보면서 하겠습니다.
- [ ] 가입하면 몇 달 동안 쓸 수 있는 무료 크레딧을 주는데, 기간이 끝나면 계정이 닫히는 경우가 있어 **유료 플랜으로 전환**해 두겠습니다.

### ⑤ (가능하면) 카카오 알림톡 — 1~2주

알림톡은 문자보다 싸지만(한 달 약 10만 원 절약), **카카오가 사업자등록증이 있는 곳에서만 보낼 수 있게** 하고 있습니다. 선생님께서 사업자등록증이 없으시면 두 가지 방법이 있습니다.

1. **원장님께 부탁드리는 방법:** 학원 사업자등록증 사본을 받아 선생님이 **학원 직원**으로 신청합니다. 카카오 채널은 학원 이름으로 만들어집니다.
2. **선생님 본인이 사업자등록을 하는 방법:** 홈택스에서 무료로 등록할 수 있지만 세금 신고 의무가 생기니 신중히 판단해 주세요.

어렵다면 **문자만으로 시작해도 전혀 문제없습니다.** 나중에 준비되면 알림톡을 추가할 수 있게 만들어 두었습니다. 진행하시게 되면 필요한 서류와 순서를 따로 안내해 드리겠습니다.

### ⑥ 시험지 분석(AI) 비용을 누가 낼지 정하기

- [ ] 시험지 분석은 AI 서비스(Anthropic Claude)를 씁니다. 이 요금(한 달 약 2.4만 ~ 8.5만 원)을 선생님 계정으로 결제하실지, 개발 담당 계정으로 하고 정산할지 정해 주세요.
- [ ] 시험지 분석을 쓰지 않으시면 이 비용은 없습니다.

### ⑦ 승인 전 마지막 확인

- [ ] 테스트 서버에서 실제 쓰시는 순서대로 한 번 해 봐 주세요.
  - 학생 등록 → 반 배정 → 일일 수업 입력 → 문자 미리보기 → 시험지 등록 → OMR 채점
- [ ] 불편한 점이나 바꾸고 싶은 점을 모두 알려 주세요. 반영한 뒤 승인을 받겠습니다.

## 4. 이전하는 날 할 일

- [ ] 선생님 휴대폰으로 **시험 문자 1통**을 받아 보시고 확인해 주세요.
- [ ] 정식 서버 원장 계정의 **비밀번호를 선생님이 직접** 새로 정해 주세요.
- [ ] 학생·반·학부모 연락처를 입력하시기 시작하면 됩니다.

## 5. 정식 운영 전에 꼭 알아 두실 점

- **학부모 동의:** 학부모 연락처를 받고 문자를 보내려면 개인정보 수집·이용 동의를 받아 두셔야 합니다. 입학 서류에 동의란을 넣어 두시는 걸 권합니다.
- **백업:** 정식 서버는 매일 자동으로 백업합니다. 실수로 지운 자료는 백업 시점으로 되돌릴 수 있지만, 그 사이 입력한 내용은 다시 넣어야 합니다.
- **삭제는 되돌릴 수 없습니다:** 학생이나 반을 "삭제"하면 그 기록(출결·성적·문자 내역)까지 함께 지워집니다. 그만둔 학생은 보통 **"퇴원"만** 해 두시면 목록에서 빠지고 기록은 남습니다.
- **비용 알림:** 첫 달 실제 사용 금액(특히 시험지 분석)을 확인해서 다시 알려 드리겠습니다.

궁금하신 점은 언제든 편하게 물어봐 주세요. 감사합니다.
