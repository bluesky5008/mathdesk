작성일 2026-10-11 받는 분 핑수 보내는 사람 용스

핑수님, 정식 서버의 인터넷 주소(예: pingsumath.com)를 사고, 그 주소로 들어오면 AWS 서버의 mathdesk가 열리도록 연결하는 순서입니다. 지난번 "정식 운영 준비 안내"의 ①(도메인 사기)과 ②(Cloudflare 가입)를 풀어 쓴 것입니다.

주소와 Cloudflare 계정은 모두 핑수님 명의로 만듭니다. 저는 핑수님 Cloudflare 계정에 관리자로 초대받아 서버와 주소를 잇는 작업만 합니다. AWS 준비와는 따로 진행해도 되니, 편하실 때 먼저 하셔도 됩니다.

터널은 핑수님 계정 안에 만든다. 터널로 가는 CNAME은 같은 Cloudflare 계정의 DNS 레코드만 프록시하므로, 내 계정의 터널로는 이 주소를 받을 수 없다. 대시보드에서 만드는 원격 관리형 터널을 쓴다. 서버에는 토큰 하나만 두면 되고(계정 인증서 cert.pem 불필요), 내 기존 cert.pem과도 충돌하지 않는다. 멤버 권한을 회수해도 터널은 계속 돈다.

5알아 두실 점

  • 매년 갱신: 주소는 1년마다 갱신됩니다. 자동 갱신을 켜 두시고, 등록한 카드가 바뀌면 Cloudflare(또는 가비아)에서 카드도 바꿔 주세요. 갱신을 놓쳐 주소가 만료되면 사이트가 열리지 않습니다.
  • 제 접근을 끊고 싶으실 때: Cloudflare Manage Account → Members에서 제 이름 → Revoke. 사이트는 계속 열립니다.
  • Cloudflare 요금: 무료 플랜과 서버 연결(터널)은 무료입니다. 나가는 돈은 주소 1년 요금뿐입니다.
