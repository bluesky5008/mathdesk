## 요약

- 결정: OMR 판독은 로컬 OpenCV 템플릿 방식으로만 수행하고, 시험지 문항 분석은 OpenAI 호환 `LlmAdapter`로 처리하되 Phase A 기본값을 외부 API로 두고 로컬 엔드포인트를 폴백으로 설정 가능하게 한다. 외부로 전송할 수 있는 데이터는 학생 식별 정보가 없는 문항 텍스트·이미지로 한정한다.
- 핵심 이유: 두 작업은 성격이 달라 같은 기술로 처리할 이유가 없고, 개인정보가 포함된 데이터는 외부로 보내지 않아도 기능을 모두 만족할 수 있다.
- 주요 단점: 외부 API 사용에 따른 종량제 비용과 공급자 의존이 생긴다.

## 배경

참조 프로그램은 OMR 이미지를 외부 LLM(OpenAI)으로 전송해 판독한다. 이 경로에는 학생 이름·수험번호가 포함된 답안지 이미지가 외부로 나간다. 한편 문항의 단원·난이도·판단 근거 서술은 zero-shot 추론과 자연어 생성이 필요해 전용 비전 모델로는 대체하기 어렵다.

## 영향을 받는 요구사항과 제약

- [NFR-04 개인정보 경계](../../requirements.md#nfr-04-상세): 학생 식별 정보와 OMR 원본은 외부 전송 금지.
- [FR-28 문항 분석 초안](../../requirements.md#기능-요구사항), [FR-29 문항 확인·수정](../../requirements.md#기능-요구사항): 분석 결과는 사용자 확정을 전제로 한다.
- [NFR-15 비용 통제](../../requirements.md#비기능-요구사항): 호출 상한과 기록이 필요하다.
- 사용자 결정: 외부 API를 기본값으로 허용하고 로컬 폴백을 둔다.

## 고려한 대안

| 대안 | 장점 | 단점·위험 | 전환 비용 |
|---|---|---|---|
| A. OMR=로컬 OpenCV, 분석=외부 LLM 기본 + 로컬 폴백 (선택) | 개인정보 경계 명확, 분석 품질 확보, 비용 예측 가능 | 외부 종량제 비용, 공급자 의존 | — |
| B. 모두 외부 VLM | 구현 단순 | 개인정보 유출 위험, 마킹 판독 오판, 페이지당 비용 | 낮음 |
| C. 모두 로컬(CPU 소형 모델) | 외부 전송 0, 비용 0 | 고3 수학 문항 분류·근거 서술 품질 부족 | 낮음(설정 변경) |
| D. 학습된 분류·분할 모델로 분석까지 대체 | 빠르고 결정적 | 라벨 수천 건 필요, 판단 근거 문장 생성 불가 | 매우 높음 |

## 결정

1. OMR 판독은 `OmrReader` 인터페이스 뒤의 로컬 OpenCV 구현만 사용한다. 이 경로에서 외부 네트워크 호출을 금지한다.
2. 문항 분석은 `QuestionAnalyzer`가 `LlmAdapter`(OpenAI 호환 `chat/completions`)를 호출한다. 엔드포인트·모델·토큰 상한은 설정값이며 로컬 엔드포인트로 교체 가능하다.
3. `QuestionAnalyzer`는 전송 페이로드를 문항 번호·문항 텍스트·문항 이미지로 제한하는 화이트리스트를 강제한다.
4. 모든 LLM 호출은 `llm_call_log`에 목적·모델·토큰·비용을 기록한다.
5. 판독기와 분석기는 인터페이스 뒤에서 교체 가능하며, 검수 화면의 교정 결과는 `label_correction`에 축적해 향후 학습 데이터로 재사용한다.

## 이유

1. 마킹 판독은 결정적이고 좌표가 고정된 문제라 템플릿 기반 처리가 더 정확하고 빠르며 비용이 0이다.
2. 문항 분류·난이도·근거 서술은 라벨 데이터 없이 품질을 내야 하므로 LLM이 적합하다.
3. 개인정보가 포함되는 유일한 이미지 경로(OMR)를 로컬로 고정하면 외부 전송 경계를 단일 어댑터에서 테스트로 강제할 수 있다(AC-27).

## 결과와 감수할 단점

- 외부 API 종량제 비용이 시험지당 발생한다. 토큰 상한과 호출 로그로 통제한다.
- 공급자 장애·정책 변경 시 분석이 중단될 수 있다. 로컬 엔드포인트 폴백 설정으로 완화하되 품질 저하를 사전 합의한다.
- OMR 정확도는 템플릿·임계값 품질에 좌우된다. [ADR-006](./ADR-006-OMR-양식-고정과-템플릿-판독.md)의 검수 절차로 보완한다.

## 후속 작업

- 토큰 상한 기본값 결정([Q-05](../../requirements.md#가정과-미해결-질문))
