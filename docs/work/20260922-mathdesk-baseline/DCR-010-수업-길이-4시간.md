# DCR-010: 수업 길이 기본값 4시간

> 문서 유형: `dcr`
> 작업 ID: `20260922-mathdesk-baseline`
> 상태: `approved`
> 기준선: `v11`
> 작성일: `2026-09-24`
> 최종 갱신: `2026-09-24`
> 관련 문서: [REQ-mathdesk: 요구사항](../../requirements.md), [DESIGN-mathdesk: 설계](../../design.md), [DCR-008](./DCR-008-주간-시간표.md), [결정 등록부](../../decisions.md)

## 요약

- 변경 분류: **요구사항 값 변경** — FR-42의 수업 길이 기본값만 바꾼다. 구조·계약·데이터 모델은 그대로다.
- 변경 요지: 수업 길이 기본값을 120분에서 **240분(4시간)**으로 바꾼다.
- 사용자 지시(2026-09-24): "수업시간은 클래스당 4시간으로 수정해줘. 2시간이 아니라 4시간이래" — 클라이언트에게 확인한 사실의 정정이며, 이 지시를 변경 승인으로 기록한다.

|---|---|---|---|---|

| output | related | [결정 등록부](../../decisions.md) | DCR-010 | 등록부 등재 |

## 변경 사유와 증거

- DCR-008에서 사용자가 수업 길이를 "2시간(120분)"으로 정했으나, 클라이언트 확인 결과 수업은 **한 번에 4시간**이다(사용자 전달 2026-09-24).
- 수업 길이는 원장이 학원 설정에서 바꿀 수 있지만, 기본값이 틀리면 운영 첫날 시간표가 절반 길이로 보인다. 기본값 자체를 바로잡는다.

## 변경 항목

| 항목 | 기존 | 변경 | 이유 |
|---|---|---|---|
| FR-42 수업 길이 기본값 | 120분 | 240분(4시간) | 클라이언트 확인 |
| `integration_setting.class_minutes` 기본값 | 120 | 240 | 위와 같음 |

허용 범위(30~480분), 원장만 변경, 캠퍼스별 저장은 바뀌지 않는다.

## 영향 범위

| 영역 | 영향 |
|---|---|
| 요구사항·설계 | 기본값 표기만 바뀐다 |
| 데이터 | 없음. 원장이 값을 저장한 캠퍼스는 저장값을 계속 쓴다(테스트 운영은 저장값이 없어 240이 된다) |
| 공개 인터페이스 | 응답 형식 같음, 기본 `class_minutes` 값만 240 |

## 마이그레이션과 롤백

- 마이그레이션: 없음. 롤백: 기본값 상수를 120으로 되돌리거나 학원 설정에서 120을 저장한다.

## 검증 방법

- `test_timetable.py`의 기본값 기대치를 240·끝 시각 22:00으로 바꿔 Red 확인 후 상수 변경으로 Green. VER-35 스텁을 4시간 수업으로 바꿔 격자 확인.
