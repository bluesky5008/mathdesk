## 요약

- 결정: OMR 답안지를 2027학년도 수능 수학영역 양식으로 고정하고, 정규화 좌표 템플릿 JSON + 모서리 마크 호모그래피 정합 + R채널 드롭아웃 + 버블 농도 판정으로 판독한다. 플래그가 있는 답안은 검수를 통과해야 채점에 반영한다.
- 핵심 이유: 양식이 고정되면 좌표 템플릿만으로 학습 없이 높은 정확도를 얻을 수 있고, 프로토타입으로 이미 검증되었다.
- 주요 단점: 다른 양식의 답안지를 쓰면 템플릿을 새로 만들어야 한다.

## 배경

클라이언트가 답안지 양식을 2027학년도 수능 수학영역 양식으로 고정했다. 이 양식은 30문항(객관식 21 + 단답형 9), 8자리 수험번호, 홀수형·짝수형 문형으로 구성되며 4개 모서리 마크와 상단 타이밍 마크를 가진다. 인쇄색이 분홍이라 R 채널에서 거의 사라진다.

[프로토타입](../../../prototype/omr/)에서 템플릿 JSON(버블 437개)과 참조 판독기를 만들고 합성 테스트(회전 3°·축소 0.6·원근 왜곡)로 30문항·수험번호·문형 전량 일치를 확인했다.

## 영향을 받는 요구사항과 제약

- [FR-33 OMR 판독](../../requirements.md#fr-33-상세), [NFR-16 OMR 정확도](../../requirements.md#비기능-요구사항): 플래그 우선 정책.
- [NFR-03 OMR 처리 시간](../../requirements.md#비기능-요구사항): CPU에서 30쪽 5분 이내.
- [NFR-04 개인정보 경계](../../requirements.md#nfr-04-상세): 스캔 이미지는 외부 전송 금지.
- [Q-08](../../requirements.md#가정과-미해결-질문): 실제 스캔본 샘플 미확보.

## 고려한 대안

| 대안 | 장점 | 단점·위험 | 전환 비용 |
|---|---|---|---|
| A. 양식 고정 + 템플릿 좌표 판독 (선택) | 학습 불필요, CPU로 빠름, 결정적, 검증 완료 | 양식 변경 시 템플릿 재생성 | — |
| B. 범용 OMR 인식(격자 자동 검출) | 양식 자유 | 정확도 하락, 개발량 큼 | 높음 |
| C. 학습된 마킹 분류 모델 | 지저분한 마킹에 강함 | 라벨 수백~수천 장 필요 | 높음(단, 인터페이스 뒤 교체 가능) |
| D. 외부 VLM 판독 | 구현 단순 | 개인정보 전송, 오판, 페이지당 비용 | 낮음 |

## 결정

1. 템플릿 ID `ksat-2027-math` 하나를 제품에 포함하고, 템플릿은 정규화 좌표 JSON으로 관리한다.
2. 판독 파이프라인: 페이지 분리 → 모서리 마크 검출 → 호모그래피로 기준 캔버스 정합 → R채널 드롭아웃 → 버블 평균 농도 → 필드별 판정(절대 임계값 + 행 내 상대 비교).
3. 판정 플래그는 `blank`·`multi`·`low_confidence`·`unmatched`이며, 임계값(`abs_th`, `rel`)은 설정값으로 노출한다.
4. 학생 매칭 키는 8자리 수험번호이며, 자리별 허용 범위를 `student.omr_number` 저장 시 검증한다.
5. 플래그가 하나라도 있는 스캔은 `needs_review` 상태가 되어 검수 전 채점에 반영하지 않는다.
6. 검수에서 교정한 값은 `label_correction`에 원본 크롭 참조와 함께 저장해 향후 학습 데이터로 축적한다.
7. 판독기는 `OmrReader` 인터페이스 뒤에 두어 학습 모델 구현으로 교체할 수 있게 한다.

## 이유

1. 양식 고정은 클라이언트가 이미 내린 운영 결정이며, 그 전제에서 템플릿 방식이 정확도·속도·비용 모두 우세하다.
2. 프로토타입 합성 테스트로 정합·판독 로직이 기하 왜곡에 견딘다는 근거가 있다.
3. 플래그 우선 정책은 오채점을 정확도 문제에서 검수 부담 문제로 바꿔 사용자가 통제할 수 있게 한다.

## 결과와 감수할 단점

- 다른 답안지 양식은 템플릿을 새로 추출해야 한다. 템플릿 생성 스크립트를 함께 유지한다.
- 임계값이 실제 스캔본으로 보정되기 전에는 현장 정확도를 보증할 수 없다([RISK-01](../../requirements.md#위험)). 임계값을 설정값으로 노출하고 샘플 확보 후 보정한다.
- 성명란 손글씨는 판독하지 않으므로 수험번호 마킹 누락 시 수동 매칭이 필요하다.
